# Task 3 — Нотатки вайб-сесії (демо-прогін)

> Еталонний приклад від автора курсу. Ваші нотатки можуть бути коротшими —
> головне конкретика і реальні числа.

**Застосунок:** Lead Desk — форма заявки + список з бейджами hot/cold,
`localStorage`. UI повністю на Porsche Design System, жодного рядка власного
CSS для компонентів (лише layout-обгортки).

## Що вийшло з першого промпту

- Каркас застосунку, форма, список, логіка hot/cold і `localStorage` — з
  одного промпту-опису на 3 речення.
- Агент сам обрав документований патерн PDS: uncontrolled-форма через
  `FormData` (компоненти form-associated) — без жодного `useState` на поле.

## Де агент (і я) спіткнулися — 4 ітерації до готового

1. **API-розбіжність версій.** Промпт спирався на документацію PDS v3, а
   встановився v4.6: у `PTag` проп називається `variant`, а не `color`; для
   email є окремий компонент `PInputEmail` (замість `type="email"` на
   `PInputText`).
   `npm run build` (TypeScript) зловив усі три помилки миттєво.
2. **«Голі» компоненти.** Все відрендерилось без стилів: у v4 базові стилі й
   CSS-токени підключаються окремо — бракувало
   `import "@porsche-design-system/components-react/index.css"` у `main.tsx`.
   Компоненти були hydrated, стилі в shadow DOM були — але всі значення
   висіли на невизначених `--p-*` токенах.
3. **Клік-тест форми** зловив нюанс: form-value синхронізується на подію
   вводу, тож миттєвий програмний сабміт «бачить» порожні поля. Для живого
   користувача це неможливо відтворити — але корисно знати.
4. Після цього — все працює: hot за терміновістю ✓, лічильники ✓, reset ✓.

## Числа

- **Ітерацій:** 1 великий промпт + 3 виправлення (build-помилки, стилі,
  перевірка форми).
- **Розмір контексту** (`npx repomix` в `app/`): 15 файлів, **13 179 токенів**.
- **Оцінка сесії:** ~15 обмінів × (контекст + історія) ≈ 60–70K вхідних +
  ~8K вихідних токенів ≈ **$0.30** на моделі середнього класу
  ($3/$15 за 1M) — за працюючий застосунок з продуктовим виглядом.

## Спостереження (що робити інакше)

1. **`npm run build` після кожної ітерації** — найдешевший детектор
   API-галюцинацій: TypeScript знає правду про встановлену версію, модель — ні.
2. **Дизайн-система окупилась одразу:** нуль часу на CSS, вигляд «як продукт».
   Але перевіряйте версію: попросіть агента зазирнути в
   `node_modules/.../*.d.ts`, якщо пропси «не сходяться».
3. **Скріншот > віра на слово:** «компоненти відрендерились» ≠ «виглядає
   правильно». Дивіться очима після кожної суттєвої зміни.
